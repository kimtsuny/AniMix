# Animix

Modern Anime Discovery Platform built with Next.js.

---

## ✨ Features

- Hero Carousel
- Anime Search
- Anime Details
- Responsive Design
- Authentication
- Modern UI

---

## 🛠 Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- GraphQL
- Prisma
- PostgreSQL
